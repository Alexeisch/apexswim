## 1. На чём написан сайт

Сайт сделан на трёх базовых технологиях веба. Никаких фреймворков, сборщиков и установки
пакетов не нужно — сайт открывается в любом браузере прямо из папки.

| Технология | Для чего | Файл |
|---|---|---|
| **HTML5** (язык разметки) | Содержимое страницы: тексты, разделы, картинки, кнопки | `index.html` |
| **CSS3** (язык стилей) | Оформление: цвета, шрифты, анимации, адаптация под телефоны | `css/style.css` |
| **JavaScript** (язык программирования) | Поведение: мобильное меню, анимация появления блоков, галерея, карта | `js/main.js` |

Структура проекта:

```
apexswim/
├── index.html      ← главная страница (тексты меняются здесь)
├── css/
│   └── style.css   ← оформление
├── js/
│   └── main.js     ← скрипты (карта, меню, галерея)
├── images/         ← сюда кладите свои фотографии
└── README.md       ← эта инструкция
```

## 2. Как открыть и проверить сайт в Visual Studio Code

> Для таких сайтов удобнее всего бесплатный **Visual Studio Code** (VS Code) от Microsoft.
> Если у вас «большая» Visual Studio (2022) — смотрите раздел 3 ниже.

### Шаг 1. Установите VS Code
1. Зайдите на https://code.visualstudio.com
2. Скачайте версию для своей системы (Windows / macOS / Linux) и установите.
3. При установке на Windows поставьте галочки **«Добавить в контекстное меню проводника»** —
   так папку можно будет открывать правой кнопкой мыши.

### Шаг 2. Скачайте проект
**Вариант А — через Git (если он установлен):**
```bash
git clone https://github.com/alexeisch/apexswim.git
```

**Вариант Б — без Git:** на странице репозитория на GitHub нажмите зелёную кнопку
**Code → Download ZIP** и распакуйте архив в любую папку.

### Шаг 3. Откройте папку в VS Code
- Меню **File → Open Folder…** (Файл → Открыть папку) и выберите папку `apexswim`.
- Слева в панели «Explorer» появятся файлы `index.html`, `css`, `js` и т.д.

### Шаг 4. Установите расширение Live Server
Это расширение запускает сайт в браузере и **автоматически обновляет страницу при каждом сохранении** файла.

1. Слева нажмите на значок **Extensions** (четыре квадратика) или `Ctrl+Shift+X`.
2. В поиске введите **Live Server** (автор — Ritwick Dey).
3. Нажмите **Install**.

### Шаг 5. Запустите сайт
- Откройте файл `index.html`.
- Нажмите правой кнопкой мыши по тексту файла → **Open with Live Server**,
  либо кнопку **Go Live** в правом нижнем углу окна VS Code.
- Откроется браузер по адресу вида `http://127.0.0.1:5500/index.html` — это и есть сайт.

### Шаг 6. Проверьте, что всё работает
- [ ] Главный экран с фоном бассейна и пузырьками.
- [ ] При прокрутке блоки плавно появляются, шапка становится тёмной.
- [ ] Кнопка «Позвонить» / номер телефона — на телефоне сразу открывает звонок.
- [ ] Клик по фото в «Галерее» открывает его крупно (закрыть — клик или `Esc`).
- [ ] В «Контактах» отображается Яндекс.Карта, кнопка «Открыть в Яндекс.Картах» работает.
- [ ] **Мобильная версия:** в браузере нажмите `F12`, затем значок телефона/планшета
  (`Ctrl+Shift+M`) — увидите, как сайт выглядит на смартфоне, и меню-«бургер».

> **Без VS Code:** можно просто дважды щёлкнуть по `index.html` — он откроется в браузере.
> Всё будет работать, только Live Server удобнее при редактировании.

> **Нужен интернет:** фотографии, шрифт и карта загружаются из интернета.
> Если какая-то фотография не загрузилась, вместо неё будет красивый «водный» градиент.

## 4. Как поменять данные на сайте

Все тексты находятся в `index.html`. Откройте его и найдите нужное через `Ctrl+F`.

### Адрес (обязательно!)
Сейчас стоит временный адрес **«г. Москва, ул. Примерная, д. 1»**.
1. Найдите в `index.html` строку с классом `js-address`:
   ```html
   <p class="js-address">г. Москва, ул. Примерная, д. 1</p>
   ```
2. Впишите настоящий адрес бассейна.
3. Готово — ссылка «Открыть в Яндекс.Картах» и карта на странице обновятся **автоматически**.

Если хотите поставить точную ссылку из Яндекс.Карт (например, на конкретную организацию):
откройте нужное место на https://yandex.ru/maps, нажмите **«Поделиться»**, скопируйте ссылку и
вставьте её в начале файла `js/main.js`:
```js
const YANDEX_MAPS_LINK = "https://yandex.ru/maps/-/ваша-ссылка";
```

### Телефон
Номер встречается в нескольких местах. В VS Code нажмите `Ctrl+Shift+H` (замена во всех файлах),
введите старый номер и новый — и замените всё разом. Номер есть в двух форматах:
`+79267917353` (в ссылках `tel:`) и `+7 (926) 791-73-53` (текст на странице).

### Фотографии
Сейчас на сайте стоят профессиональные фото с бесплатного фотобанка Unsplash.
Чтобы поставить свои (например, настоящее фото Ивана Ивановича):
1. Положите файл в папку `images`, например `images/ivan.jpg`.
2. В `index.html` найдите нужную картинку (`<img src="...">`) и замените адрес на `images/ivan.jpg`.

### Цвета
В начале файла `css/style.css` в блоке `:root` собраны все основные цвета — меняйте их там.

## 5. Как выложить сайт в интернет (бесплатно)

Самый простой способ — **GitHub Pages**:
1. В репозитории на GitHub: **Settings → Pages**.
2. В «Source» выберите ветку (например `main`) и папку `/ (root)`, нажмите **Save**.
3. Через минуту сайт будет доступен по адресу `https://alexeisch.github.io/apexswim/`.
